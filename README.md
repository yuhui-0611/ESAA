# ESAA

데이터 분석 학회 **ESAA** 활동 중 수행한 데이터 분석, 머신러닝, 딥러닝 프로젝트와 학습 내용을 정리한 repository입니다.
정형 데이터 분석, NLP, 추천 시스템, 머신러닝 및 딥러닝 모델링 경험을 포함합니다.

## Projects

| Project                                                                        | Description                                       | Main Topics                                       |
| ------------------------------------------------------------------------------ | ------------------------------------------------- | ------------------------------------------------- |
| [Movie Box Office Prediction](./Projects/01_Movie_BoxOffice_Prediction)        | 영화 특성을 활용한 관객 수 예측                                | EDA, Regression, Feature Engineering              |
| [Hotel Reservation Cancellation](./Projects/02_Hotel_Reservation_Cancellation) | 호텔 예약 고객의 예약 취소 여부 예측                             | Classification, XGBoost, CatBoost                 |
| [Author Classification NLP](./Projects/03_Author_Classification_NLP)           | 텍스트 데이터를 활용한 소설 작가 분류                             | NLP, TF-IDF, Text Classification                  |
| [Bank Marketing Hackathon](./Projects/04_Bank_Marketing_Hackathon)             | 금융기관 고객의 정기예금 가입 여부 예측                            | Classification, Imbalanced Data                   |
| [Real Estate Investment](./Projects/05_Real_Estate_Investment)                 | 가구 및 경제 데이터를 활용한 부동산 투자 의사결정 예측 및 영향 요인 분석        | XGBoost, SHAP, Classification                     |
| [Olist E-commerce Analysis](./Projects/06_Olist_Ecommerce_Analysis)            | 브라질 E-commerce 데이터를 활용한 고객 분석 및 셀러 이탈 예측          | RFM, NLP, XGBoost, LightGBM, SHAP                 |
| [Poverty Prediction Challenge](./Projects/07_Poverty_Prediction)               | 가구 설문 데이터를 활용해 소비 및 빈곤 수준을 예측하고 다양한 전처리·모델링 전략 비교 | Regression, Feature Engineering, Machine Learning |
