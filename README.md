# ESAA

데이터 분석 학회 **ESAA**에서 진행한 데이터 분석, 머신러닝, 딥러닝 프로젝트와 학습 내용을 정리한 repository입니다.

## Projects

| Project                        | Description                        | Main Topics                          |
| ------------------------------ | ---------------------------------- | ------------------------------------ |
| Movie Box Office Prediction    | 영화 특성을 활용한 관객 수 예측                 | EDA, Regression, Feature Engineering |
| Hotel Reservation Cancellation | 호텔 예약 고객의 예약 취소 여부 예측              | Classification, XGBoost, CatBoost    |
| Author Classification NLP      | 텍스트 데이터를 활용한 소설 작가 분류              | NLP, TF-IDF, Text Classification     |
| Bank Marketing Hackathon       | 금융기관 고객의 정기예금 가입 여부 예측             | Classification, Imbalanced Data      |
| Real Estate Investment         | 부동산 투자 의사결정 예측                     | XGBoost, Classification              |
| Olist E-commerce Analysis      | 브라질 E-commerce 데이터를 활용한 고객 및 셀러 분석 | EDA, RFM, Customer Analysis          |
| Poverty Prediction             | 가구 설문 데이터를 활용한 빈곤 수준 예측            | Regression, Machine Learning         |
